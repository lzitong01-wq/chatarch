## 解决什么问题

每一段被认真对待的人机协作对话里，都埋着比结论更值钱的东西：那些被推翻的方向、被删掉的段落、反复纠结的卡点、灵光乍现的瞬间。它们从不出现在任何导出文档里。ChatArch 做的是"对话的考古学"——把这些被埋没的过程价值发掘出来，变成可以回看、可以分享的考古现场。

适用场景：个人复盘（看清自己怎么和 AI 把一件事磨出来的）、团队沉淀（复盘协作模式）、内容创作（展示思考过程的戏剧性）。

## 功能亮点（对齐评审标准）

**创意与场景价值（35）**
- "对话考古学"概念完整落地：发掘（多格式自动识别解析）→ 断代（事件锚定阶段划分）→ 陈列（四视图 + 博物馆图录视觉）
- 废稿博物馆：把"死掉"的产出按生卒时间陈列，标注死因（用户原话）与是否被重写——这是任何导出文档都不会给你的视角
- 启发式分析的诚实边界：不声称理解语义，每个结论附触发文本可点击核对

**作品完成度（40）**
- 解析引擎支持 5 种输入格式：角色标记（用户/助手、Human/Assistant、Q/A）、Markdown 标题、emoji 角色、JSON 导出数组、纯文本兜底
- 分析引擎：阶段划分（事件锚定，无强信号时诚实呈现单阶段，不虚构叙事）、事件流（方向变更/否决/犹豫/突破/定稿，全部可溯源）、废稿检测（生卒判定 revised/abandoned）、卡点聚类（信号密度加权）、人机贡献统计
- 四视图：编年史（地层剖面 + 竖排阶段名 + 深度标尺）、废稿博物馆、协作画像（配比条 + 50 根节奏柱）、卡点热区
- 报告导出：Markdown 全文 + Canvas 手绘 2x 高清报告卡（PNG 约 390KB）

**使用体验（25）**
- 着陆页一句话讲死价值，三步叙事（壹发掘/贰断代/叁陈列）
- 评委 3 分钟路径：点「载入示例」→ 看四视图 → 导出报告，全程无学习成本
- 考古主题设计系统：土层色板、朱砂印章、纸纹肌理、竖排阶段名、地层剖面深度标尺
- 移动端 375px 零溢出；全程 0 console 错误

## 技术实现

- 纯前端：UMD 模块模式，浏览器全局挂载 + Node require 双端可用；无框架、无构建、无外部 CDN
- 分析引擎为启发式算法：用词信号（正则词库）+ 消息长度 + 结构推断协作事件
- 图表全部手绘（DOM/SVG/Canvas 2x）
- 质量保障：27 个单元测试（Node test runner）+ 37 项浏览器 E2E 全通过，0 console 错误

## 使用方式

1. 打开链接，点「载入示例」（50 轮税务竞赛论文创作对话，含 2 次方向变更、3 份废稿、1 个卡点）
2. 或粘贴自己的对话记录（支持上述 5 种格式，自动识别）
3. 点「开始发掘」，依次查看四个视图
4. 在「考古报告」页导出图片或文本
